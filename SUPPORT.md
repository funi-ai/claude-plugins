# Getting help

Start with `/genmedia-skills:setup` inside Claude Code. It runs free checks only and names whatever is missing or misconfigured. The Troubleshooting section of the [plugin README](plugins/genmedia-skills/README.md#troubleshooting) covers the common install and permission problems.

Where to go next depends on the problem:

| Problem | Where |
|---|---|
| A skill or script misbehaves | [Bug report](https://github.com/funi-ai/claude-plugins/issues/new?template=bug_report.yml) |
| A model ID no longer works or a price is wrong | [Model or price out of date](https://github.com/funi-ai/claude-plugins/issues/new?template=routing.yml) |
| An idea for a skill or a change to one | [Feature request](https://github.com/funi-ai/claude-plugins/issues/new?template=feature_request.yml) |
| How to do something with the plugin | [Question](https://github.com/funi-ai/claude-plugins/issues/new?template=question.yml) |
| A security problem | Private report, see [SECURITY.md](SECURITY.md) |
| Your fal account, credits, API keys or a generation on fal's side | fal, through your [fal dashboard](https://fal.ai/dashboard) |
| Claude Code itself, also without this plugin | [Claude Code issues](https://github.com/anthropics/claude-code/issues) |

For anything that shouldn't be public, email support@funi.ai.

Answers can take a few days. Issues with exact steps, versions and error output are the quickest to fix.
