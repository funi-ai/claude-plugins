# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The short version for this repository:

Be considerate and stay on topic. Criticize code, prompts and decisions, not the people behind them. Harassment, insults, personal attacks, sexual content and posting someone's private information are not acceptable here. Neither is posting another person's API keys, likeness or private media.

The maintainers may edit, hide or delete comments, lock threads and block accounts that break these rules.

Report a conduct problem to support@funi.ai. We keep reports confidential.
